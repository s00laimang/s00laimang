**Asset types**
- 🖼 **Screenshot**: a still image you take
- 🎬 **Recording**: a 10–15 second screen recording
- 💻 **Code**: a short code image
- 😂 **Meme**: a meme image
- ✍️ **Text**: text only, no image
- 🧵 **Thread**: a post with replies under it
- 🔁 **Before/after**: two images side by side

**Status**
- ✅ **Ready**: you can post it now
- 🛠 **Make asset**: you need to make the image or video first
- 🔒 **Wait**: needs someone's OK or a pitch to finish first

## How to make each type of asset

**💻 Code images**
- Use ray.so (dark theme, one language), at most 15 lines.
- Paste the code as text in a reply too, so people can copy it.
- Only post code I've marked safe or rewritten as a generic example.

**🖼 Screenshots**
- One image: 16:9.
- 2–4 images: square, because X crops them.
- Blur names, emails, phones and prices before posting.
- Your Shot Studio (`Personal\content-studio\mockup.html`) gives them a nice frame.

**🎬 Recordings**
- 10–15 seconds. X only counts a video view after about 8 seconds.
- Most people watch muted, so put one short line of text on the first frame.
- MP4 at 1080p. No watermark.
- Check the last frame for anything personal.

**😂 Memes**
- imgflip.com works fine.
- Base them on real moments only.
- At most one a week. The caption should still say what you actually built.

**✍️ Text**
- First line: a specific claim or story.
- Name the real thing (Google Maps, WhatsApp, a booking form).
- Leave links for a reply.
